# Aura English — Official Website

This is the official web application for **Aura English**, built with Next.js, React, TypeScript, Tailwind CSS, and Framer Motion.

## Brand Philosophy & Tagline
**Expand Yourself.**  
A modern, premium English platform designed around confidence, opportunities, and personal growth.

## Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS v4 + Custom Glassmorphism & Atmospheric Glow system
- **Animations**: Framer Motion & CSS custom transitions
- **Icons**: Lucide Icons
- **Fonts**: Metrophobic, Comfortaa, Public Sans

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## Build for Production

```bash
npm run build
```
